# Kernel Data Structures

**F.CSM302 — Үйлдлийн систем | Бие даалт 1**

**Багийн код:** II-4-4

**Сэдэв:** Linux Kernel Data Structures  
**Үндсэн дүрслэл:** Kernel Structure Graph

## 1. Төслийн танилцуулга

Энэхүү төсөл нь *Operating System Concepts (10th Edition, 2018)* сурах бичгийн Бүлэг 3 — Processes сэдэвтэй холбогдох **Kernel Data Structures** программчлалын төслийг судалж, хэрэгжүүлэх зорилготой.

Linux kernel-д ашиглагддаг өгөгдлийн бүтцийн ажиллагааг судалж, элемент нэмэх (Insert), устгах (Delete), хайх (Search) үйлдлүүдийг хэрэгжүүлэн, үр дүнг интерактив график интерфейсээр дүрслэн харуулна.

## 2. Төслийн зорилго

- Linux kernel-ийн өгөгдлийн бүтцийн зохион байгуулалтыг судлах.
- Сурах бичгийн Programming Project-ийн үндсэн шаардлагыг хэрэгжүүлэх.
- Өгөгдлийн бүтцэд элемент нэмэх, устгах, хайх үйлдлийг гүйцэтгэх.
- Өгөгдлийн бүтцийн төлөвийг Kernel Structure Graph хэлбэрээр харуулах.
- Хэрэглэгч өөр өгөгдөл оруулж, туршилтыг дахин ажиллуулах боломжтой болгох.
- Үндсэн болон нэмэлт тестээр зөв ажиллагааг шалгах.

## 3. Ашиглах технологи

Төлөвлөж буй хөгжүүлэлтийн орчин:

- **Operating System:** Ubuntu Linux

UI технологи болон бусад шаардлагатай санг хэрэгжүүлэлтийн явцад тодорхойлно.
