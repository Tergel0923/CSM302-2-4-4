# Хамгаалалтын үеэр үзүүлэх туршилт

## Вэбийг нээх

`make doctor` командаар Python хувилбараа шалгаад `make demo` ажиллуулна. Хөтөч дээр http://127.0.0.1:8765 нээнэ. Дадлагын горим нь цөмийн бодит туршилтыг орлохгүй.

## Өнгийн жагсаалтын жишээ

1. «Анхны 4 элементийг сэргээх» дарна. HEAD.next=1, HEAD.prev=4 байна.
2. «RGB 10,20,30» жишээ товчийг дарна. Энэ нь зөвхөн оролтыг бэлдэнэ.
3. «Нэмэх» дарна: 5 элементтэй болж, 5 дугаартай элемент сүүлд нэмэгдэнэ.
4. «RGB утгаар хайх» дарна: 5 дугаартай элемент шар хүрээтэй болно.
5. Граф дээрх элементийг товших буюу Tab-аар сонгоод Enter дарна. RGB ба устгах дугаар автоматаар бөглөгдөнө.
6. «Устгах» дарна. 4.next=0, HEAD.prev=4 болж холбоос шинэчлэгдэнэ.
7. «Хоослох» дарна. HEAD.next=HEAD.prev=0 болно.

## Коллатцын жишээ

«Коллатц 15» жишээ → «Дадлагын дараалал үүсгэх»: 18 элемент; эхний утга 15, сүүлийн утга 1. «Коллатц 27» жишээ: 112 элемент. Жишээ сонгох нь өөрөө дараалал үүсгэхгүй.

Бодит горимд start параметрийг терминалаас өөрчилж модулийг дахин ачаална. Жишээ товч нь энд ч зөвхөн оролт бэлдэх тул kernel module-ийг өөрчлөхгүй.

## Автомат шинэчлэлт ба нотолгоо

«2 секунд тутам төлөв шинэчлэх»-ийг сонговол нээлттэй хуудсанд шинэ төлөв уншина. Өөр tab/терминалын өөрчлөлт графт харагдана. Хүсэлт давхцахгүй; далд tab үед автоматаар уншихгүй. Унших үйлдэл нь үйлдлийн түүхт нэмэгдэхгүй.

Үйлдлийн түүх нь амжилт болон алдааг монгол тайлбар, локал цагтай харуулна. JSON татахад өмнөх шиг командын машинд уншигдах нэр болон snapshot хадгалагдана. Хуудас дахин ачаалахад түүх арилна.

Дэлгэцийн зураг бүр дээр горим, оролт, элементийн тоо болон үр дүнг хамтад нь харуулна. Бодит цөмийн screenshot-ийг Ubuntu дээр модуль ачаалсны дараа авна.


## Шинэ интерфейсийн автомат шалгалт

Node.js суулгасан бол `make test-ui` ажиллуулна. Хөнгөн DOM орлуулагчаар жишээ товч backend-д өөрчлөлт хийхгүй байх, графын сонголт, давхар хүсэлтээс хамгаалалт, алдааны түүхийг шалгана. Энэ нь бодит хөтчийн харагдах байдлын шалгалт биш.
